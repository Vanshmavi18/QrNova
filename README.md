# QrNova 🚀

QrNova is a modern, high-performance QR code generator and management platform designed for speed, customization, and seamless sharing.

## ✨ Features (Planned)
- **Instant QR Code Generation**: URL, Text, Wi-Fi, vCard, Email, and SMS.
- **Dynamic Customization**: Custom colors, gradients, logo embedding, and shapes.
- **Multiple Export Formats**: High-resolution PNG, SVG, and PDF downloads.
- **Analytics & Tracking**: Scan counts, device insights, and geographic distribution.
- **Modern Glassmorphic UI**: Sleek, responsive, and intuitive interface with dark/light themes.

## 🛠️ Tech Stack
- Frontend: HTML5 / Modern CSS / JavaScript (or Vite + React/Next.js)
- QR Engine: High-performance canvas-based QR rendering

## 📦 Getting Started

# Clone the repository
git clone https://github.com/Vanshmavi18/QrNova.git
